# Jampa Vibes

Crie um protótipo web completo, moderno, responsivo e navegável de uma plataforma de descoberta de negócios e lugares de João Pessoa, Paraíba.

IMPORTANTE:

Este é um PROTÓTIPO DE CONCEITO INICIAL para apresentar uma ideia a um possível parceiro. Não quero ainda backend, autenticação, banco de dados, pagamentos reais ou funcionalidades complexas. O foco é criar uma experiência visual muito bem acabada que demonstre como o produto poderia funcionar.

A plataforma será inspirada no conceito de "Melhores do Ano João Pessoa", mas evoluindo a ideia de uma premiação anual para uma plataforma que funcione durante todo o ano.

A ideia central é unir três conceitos:

1. 🏆 MELHORES DO ANO

Histórico das premiações e empresas/lugares que já foram reconhecidos.

2. 🔥 DESTAQUES

Uma área comercial onde negócios podem aparecer em destaque durante determinado período. A inspiração é um sistema de ranking/visibilidade em que negócios podem disputar posições de destaque.

3. 🔎 DESCOBRIR

Uma área voltada ao consumidor para pesquisar e descobrir restaurantes, bares, academias, salões, lojas, serviços e outros negócios de João Pessoa.

O produto deve parecer uma mistura de:

- guia local premium;

- plataforma de descoberta;

- mídia local;

- premiação;

- marketplace de visibilidade para empresas.

NÃO quero que pareça um dashboard SaaS tradicional.

CONCEITO DE DESTAQUES

==================================================

O conceito comercial é inspirado em plataformas de ranking/visibilidade.

Quero que a interface deixe isso evidente, mas sem parecer um cassino ou sistema agressivo de leilão.

A lógica conceitual:

Empresas podem pagar para aumentar sua exposição.

Quanto maior a participação comercial, maior a possibilidade de aparecer em posições mais visíveis.

Porém:

PAGAR NÃO SIGNIFICA SER O MELHOR.

Por isso, separar claramente:

🏆 Premiado

Resultado de uma premiação.

❤️ Mais votado

Resultado de votação da comunidade, caso essa funcionalidade exista futuramente.

🔥 Em destaque

Visibilidade comercial.

📈 Em alta

Indicador de interesse/atividade recente.

No protótipo, mostrar esses conceitos visualmente.

==================================================

OBJETIVO DO PROTÓTIPO

==================================================

O objetivo principal é fazer uma pessoa olhar para o site e imediatamente entender:

"Isso é uma plataforma onde as pessoas descobrem os melhores lugares e negócios de João Pessoa, enquanto as empresas podem ganhar visibilidade durante o ano inteiro."

O site deve passar a sensação de que:

"Melhores do Ano" deixa de ser apenas um evento anual e passa a ser o núcleo de uma plataforma local que funciona durante todo o ano.

A experiência deve parecer suficientemente profissional para ser apresentada ao proprietário da página "Melhores do Ano João Pessoa" como uma proposta inicial de parceria.

NÃO construir algo excessivamente complexo.

Priorize:

1. Design

2. Navegação

3. Clareza da proposta

4. Sensação de produto real

5. Experiência mobile

6. Qualidade visual dos cards e imagens

7. Separação clara entre premiação e publicidade
